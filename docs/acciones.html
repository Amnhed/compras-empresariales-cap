Acciones

Aprobar y rechazar no son un PATCH del campo estado. Son operaciones de negocio.

Arquitectura Modelo CDS Servicio OData CRUD Acciones Seguridad

En el servicio se declaran ligadas a la orden. En HTTP son un POST a la acción, no un PATCH:

POST /odata/v4/compras/OrdenesCompra(ID=<uuid>,IsActiveEntity=true)/ComprasService.aprobar
POST /odata/v4/compras/OrdenesCompra(ID=<uuid>,IsActiveEntity=true)/ComprasService.rechazar

El handler on sustituye la implementación genérica. Solo acepta una orden en Retenida - Requiere Revisión. Aprobar la deja en Aprobada. Rechazar la deja en Rechazada. Una orden aprobada automáticamente no pasa por aquí: el monto no llegó al umbral.

this.on('aprobar', OrdenesCompra, async (req) => {
    await cambiarEstado(req, OrdenesCompra, APROBADA, 'aprobar');
});
this.on('rechazar', OrdenesCompra, async (req) => {
    await cambiarEstado(req, OrdenesCompra, RECHAZADA, 'rechazar');
});
