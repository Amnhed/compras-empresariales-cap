Modelo CDS

Archivo db/schema.cds. CDS no es la base ni el protocolo: es el lenguaje del modelo.

CAP lee este archivo al arrancar y crea las tablas en SQLite. El namespace sap.compras evita chocar con otros modelos.

  • cuid agrega la clave ID, un UUID.
  • managed agrega quién y cuándo creó o cambió la fila (createdAt, createdBy, modifiedAt, modifiedBy).
  • La asociación apunta de la posición hacia la orden. La composición dice que esas posiciones no viven solas: si se borra la orden, se borran sus artículos.
  • virtual declara importeTotal sin columna. El número se calcula al leer.
namespace sap.compras;
using { cuid, managed } from '@sap/cds/common';

entity OrdenesCompra : cuid, managed {
    folio       : String(20) not null;
    estado      : String(30) default 'Pendiente';
    posiciones  : Composition of many Posiciones on posiciones.orden = $self;
    virtual importeTotal : Decimal(15, 2);
}

entity Posiciones : cuid {
    orden          : Association to OrdenesCompra;
    material       : String(100) not null;
    cantidad       : Integer not null;
    precioUnitario : Decimal(10, 2) not null;
}

Pendiente es solo el valor inicial. Al guardar el registro, el handler de CREATE lo reemplaza por aprobada automáticamente o retenida.
